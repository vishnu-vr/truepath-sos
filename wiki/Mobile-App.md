# Mobile app (TruePath Care)

Flutter app in `app/`, package `app.truepath.truepath_care`, Android-first.
Backend base URL: `app/lib/config.dart` (10.0.2.2 = host Mac from the
Android emulator).

## Files

| File | Role |
| ---- | ---- |
| `lib/main.dart` | Firebase init, FCM background handler, `AuthGate` (auth stream → AuthScreen/HomeScreen), `markAlertResolved()` |
| `lib/config.dart` | backend base URL |
| `lib/api.dart` | `backend(path, body)` — authenticated POST, throws `BackendException` with the server's message |
| `lib/push_service.dart` | notification permission, `sos_alerts` max-importance channel, token → `users/{uid}.fcmTokens`, foreground display, tap → SOS screen (background + terminated) |
| `lib/screens/auth_screen.dart` | sign in / create account (creates `users/{uid}` doc) |
| `lib/screens/home_screen.dart` | tabs: Alerts (active + history, live query on `memberUids`) and My canes (two queries: caregiver-of, cane-user-of); FAB → ClaimScreen |
| `lib/screens/claim_screen.dart` | QR scan (mobile_scanner) or manual claim-code entry → `/claim` |
| `lib/screens/cane_screen.dart` | cane status + people with Owner/Primary/Cane-user badges; owner/primary get add/remove/make-primary/link/rename via `/manage` |
| `lib/screens/alert_detail_screen.dart` | SOS screen: name/time/location/battery/status, Open in Maps, Mark Resolved (shown to caregivers only) |

## Android build specifics (already configured — don't undo)

- `compileSdk = 37` (flutter_local_notifications requirement).
- Core library desugaring enabled + `desugar_jdk_libs:2.1.5` dependency.
- Manifest: `POST_NOTIFICATIONS` permission and
  `firebase_messaging_installation_id_enabled=true` meta-data (required by
  firebase_messaging's `register()`/`onRegistered` token API).
- `android/gradle/wrapper/gradle-wrapper.properties` points at a LOCAL gradle
  zip — see [Dev environment](Dev-Environment.md).
- Firebase config: `lib/firebase_options.dart` + `google-services.json`,
  both generated by `flutterfire configure`.

## Push flow

Backend sends notification + data (`alertId`, coords). Android displays it
automatically when the app is background/terminated (channel `sos_alerts`,
created by the app at startup). Foreground messages are displayed via
flutter_local_notifications. Any tap routes to `AlertDetailScreen(alertId)`,
including cold starts (`getInitialMessage`).

## Build & run

```bash
cd app
export JAVA_TOOL_OPTIONS=-Djava.net.preferIPv4Stack=true
flutter build apk --debug          # or: flutter run
```
VS Code: F5 ("TruePath Care (debug)") or the "app: build debug APK" task.
